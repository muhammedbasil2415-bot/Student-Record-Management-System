# Student Record Management System

## Project Overview
A menu-driven Student Record Management System developed using C programming.

The project uses a Singly Linked List to manage student records dynamically.

## Features
- Add student records
- Delete student records
- Display student records
- Modify student details
- Save and load records using file handling
- Sort records by name
- Sort records by percentage
- Reverse the linked list
- Delete all records

## Technologies Used
- C Programming
- Singly Linked List
- Dynamic Memory Allocation
- File Handling
- Makefile

## Compilation
Run:

    make

## Execution
Run:

    ./exe

## Clean
Run:

    make clean
